## Problem Statement

部署者需要运行在 Cloudflare Workers 免费套餐上的可自定义 DNS 服务，而不是旧版业务策略的复刻。部署者只想通过环境变量中的 JSON 组合基础条件和动作，不希望编写 JS/TS 扩展，也不希望核心替自己决定回退、重试或答案采用策略。

已有 DNS WASM、ECH 探测库和 DoH 应用提供基础，但旧实现的代码注册入口、默认补查和自动上游组回退与新边界不符。核心需要提供可靠的传输、协议处理、动作结果、回滚和资源管理，让使用者可以用顺序规则表达自己的处理流程，而不是不断增加高级策略开关。

失败必须可见，原始数据和缓存不得污染，外部列表更新失败不得静默沿用旧数据。免费套餐兼容性必须通过线上 CPU 测量验证，不能由本地正确性或网络经过时间代替。

## Solution

建立单部署、单套共享配置的 JSON 驱动 DoH 服务。应用配置只来自运行时环境变量，敏感值由 Secret 提供。每个规则组独立保存并确定排序，组内规则和动作顺序执行。

核心提供声明式条件、顺序组合、条件分支和基础动作，不提供用户代码注册、循环、通用并发或竞速。命名上游只保存连接信息；一次上游请求动作只针对指定来源请求一次，不执行自动回退、重试或默认补查。使用者根据当前响应和只读最近动作结果，用 JSON 编排顺序回退。

保留默认上游原始响应缓存，并允许规则调整读、写及有效期上限。保留标准 DoH、可选 JSON 查询入口、路径密钥、记录改写、外部域名列表、显式地址归属补全和 ECH 库薄适配。先迁移既有实现，再逐步交付新能力及完整线上验收，不重写已推送历史。

## Implementation Decisions

### 配置及 JSON 能力边界

- 全部应用配置来自运行时环境变量，不保留文件回退。普通配置用 JSON，敏感值使用 Secret 引用；不接受请求上传配置、代码或任意目标。
- 每个规则组使用 DNS_RULE_ 前缀的独立变量；必填整数 order 升序，同序按变量名稳定排序；规则及动作数组有序。接受平台 JSON 值或 JSON 文本，进入统一校验。
- 全量预检字段、类型、参数及上游和来源引用，包括不可达分支；未知或已移除配置明确报错，不静默忽略，也不兼容成旧自动政策。
- 使用者不注册条件或动作代码。移除用户函数注册入口及其 JSON 引用；应用内部调用通用库不属于用户代码扩展。
- 提供顺序处理与声明式条件分支，不提供循环、通用并发或竞速；不能以换名的并发原语重新加入已取消能力。
- 保留既有环境变量容量边界：单变量 5 KB、免费套餐普通变量与 Secret 合计 64 个。运行时配置需保存并部署，不声称每个请求实时读取面板；部署工具不得意外覆盖面板变量。

### 条件与数据

- 保留 all/any/not、严格类型比较、缺失与存在性、集合任意/全部及同项绑定。空集和缺失语义明确，不把不可用来源或执行错误自然降为 false。
- 域名遵守标签边界，区分精确、含自身后缀、仅子域、单级/多级通配符和正则；区分当前/原始查询名、记录所属名和 CNAME 等目标字段。
- 每条规则进入时判断一次条件，后续规则读取当前状态。条件不隐式联网。
- 客户端网络属性、响应地址归属及边缘位置分别建模；不使用入站属性冒充答案地址属性，也不伪造缺失值。
- 响应地址归属补全是来源可配置的显式动作，可缓存；多属性匹配绑定同一地址。补全来源不默认绑定厂商。

### 动作、状态与最近动作结果

- 原始查询及上游原始响应只读且与工作状态隔离。上游请求成功以新响应替换当前响应，不隐式合并；此前状态不得通过共享引用污染缓存。
- 默认继续；stop 停止规则后统一收尾，return 必须已有响应。正常结束或 stop 后无响应时记录错误并返回相关 SERVFAIL，不请求默认上游。所有合法 DNS 响应都属于已有响应，不仅限于 NOERROR/NXDOMAIN。
- 必需动作失败终止；可选动作失败丢弃自身 DNS 修改、保留此前成功状态、记录错误并继续。网络、日志及已发生的来源更新等外部副作用不承诺撤销。
- 提供只读最近动作结果：成功或失败、动作定位及可用的稳定脱敏错误码；与当前 DNS 响应分开，失败后的结果不随 DNS 回滚消失，成功动作也更新结果，避免旧错误残留冒充最近状态。具体字段名由接口设计确定，不把完整异常或敏感值放入结果。
- 使用者用可选请求、最近动作结果和响应条件组合顺序回退。核心不自动选择下一个来源，也不提供上游组采用政策。
- 所有返回路径执行协议及 DNSSEC 一致性收尾；改写清 AD 并移除受影响失效签名，未改写数据保留适用信息。修改 EDNS 时不得丢失扩展 RCODE 或错误保留认证元数据。
- 事件关联请求、组、规则及动作，记录错误码、安全信息与回滚/继续/终止处置；后续成功不抹去既有失败。默认日志和最近结果不转储配置、完整报文、原始异常、认证信息或完整敏感 URL。

### 命名上游和传输

- 一个专用 JSON 环境变量 DNS_UPSTREAMS 保存上游名称、地址和连接方式；支持 Secret 引用敏感连接信息。名称用于复用来源，不表示带策略的上游组；具体地址字段和 Secret 表达由实现接口确定。
- 目标传输为 https（标准 DoH）、tcp（普通 DNS over TCP，默认端口 53）、tls（DNS over TLS，默认端口 853）。TCP/TLS 使用标准两字节长度前缀；TLS 验证服务端身份，不静默关闭认证或降为明文。
- Workers 原生 TCP API 提供实现基础；目标地址、证书身份配置和网络限制必须真实验证，不能宣称任意目标可达。遇到 TLS 实际阻塞时报告并协商，用户允许在确有复杂性阻塞时先交付 HTTPS/TCP，但不得未经报告静默删掉 TLS 目标。
- 一次请求动作明确引用一个上游；缓存未命中或绕过时仅发一次请求，不隐式重试、跟随连接失败切换传输或请求其他来源。移除隐式默认上游、默认组和自动回退策略。
- 核心校验传输、消息大小、协议与实际出站查询对应关系；HTTP 200 不足以证明 DNS 有效。所有协议有效且可表示的完整 RCODE 响应均交给规则，包括 SERVFAIL、REFUSED、NXDOMAIN 和空答案。不得继续把 NOERROR/NXDOMAIN 写成默认采用白名单。
- 协议失败与不满意的合法响应分开。使用者条件不能使损坏或不对应响应成为合法答案；错误及迟到拒绝脱敏处理，连接/流/计时器/监听器在完成、超时和取消后清理。

### 默认缓存及规则控制

- 默认对安全可复用的上游原始响应执行缓存；命中发生于显式请求动作，不因此触发额外上游请求，且不跳过后续规则。自定义或最终改写答案不进入通用上游缓存。
- 规则可设置后续请求的缓存读取、写入及有效期上限，请求动作可局部覆盖；优先级为请求动作覆盖规则策略，规则策略覆盖默认值，作用域不得污染其他请求。字段名和具体保守数值由实现接口与验收明确。
- 有效期上限只能缩短安全复用时间，不延长原始 TTL；正确递减 TTL、执行 DNS 负缓存规则并恢复本次请求关联。故障响应和不安全查询不因用户设置而自动变为可缓存。
- 缓存身份涵盖上游来源和传输身份及影响答案的查询参数，包括适用 EDNS/ECS、DO/CD；不开放随意忽略身份差异的缓存键，不支持把过期数据当成未过期答案。
- 上游原始对象、缓存副本和工作状态隔离。边缘缓存不保证命中、永久保存或全局一致；不为基础缓存强制引入额外持久化服务。

### 域名列表及来源维护

- 支持内联列表及明确配置的外部 HTTPS 来源；首版格式为逐行域名文本和 JSON 域名数组。来源只是数据，不是远程可执行规则。
- 配置来源和刷新间隔后由核心维护，条件匹配本身不下载。首次未加载或更新失败时来源不可用；不要求使用者在每次请求里显式安排加载。
- 完整下载及校验成功后原子替换。首次失败、HTTP 失败、部分下载及校验失败都明确报告；更新失败即使旧数据仍存在也不得使用，不当空列表或普通未命中；再次完整成功后恢复。
- 刷新间隔不同于 DNS TTL；调度机制、刷新与匹配的边界、首次加载、失效作用域、重试和跨实例可见性在实现设计中明确。不以进程内标志声称全球同时失效。

### ECH、改写与资源

- DNS/ECH 通用库继续独立，不把应用政策写回基础库。保留直接 ECH 配置、从 DNS HTTPS 数据取得 ECH，以及通过现有库发起 TLS retry-config 探测的明确路径。
- JSON ECH 动作是现有库的薄适配：按库公开参数调用，返回数据供后续 HTTPS 记录修改动作使用；应用负责 JSON 参数校验、结果传递、预算、取消和脱敏错误，不另造 TLS 探测协议，不开放任意函数调用。
- 沿用库公开的目标、端口、服务名、ALPN、时间/字节预算和认证选项契约；默认开启证书认证。显式认证选项遵循库语义，但应用绝不自动关闭认证、隐式选择厂商或因失败切换来源。
- 普通请求不默认探测；获取时机和复用显式配置。ECH 有效性、列表失败即失效与 DNS TTL 是不同政策，不混为同一缓存。
- 输入、配置复杂度、记录、来源大小、连接次数、总耗时及 CPU 工作设保守可配置边界；所有顺序动作共享请求预算，不通过可选失败重置整体限制。TLS/ECH/来源维护也必须计入适用资源约束。
- 免费套餐是默认和内置场景的完整验收要求；网络等待不等于 CPU，后台任务与 Cron 不解除 CPU 限制。

### 接口及访问控制

- 标准入口支持 RFC 8484 GET/POST、DNS wire-format；保留可选 JSON 查询适配并复用同一执行器。JSON-only 指使用者配置，不表示取消标准 wire 入口。
- 单部署单配置，无账户或多租户。可选访问密钥仅放路径，来自 Secret；认证先于规则执行和非必要来源/网络工作。应用日志隐藏密钥路径，不能保证外部代理或客户端不记录 URL。
- 无效 HTTP/DoH 输入与合法 DNS 查询执行失败分别处理。合法查询无答案或必需动作失败返回相关 SERVFAIL，不把无效 HTTP 输入伪装成正常 DNS 响应。

## Testing Decisions

### 接缝：本轮已由用户确认

- 主接缝为真实 workerd 的公开 DoH HTTP 入口。发送 HTTP/DNS 和 JSON 环境变量，观察响应、实际出站请求、来源访问和脱敏事件；尽量用一条公开入口覆盖跨模块行为。
- TCP/TLS 同样经公开 DoH 入口驱动受控本地 DNS TCP/TLS 服务，验证长度前缀、分段读写、超时、断连和 TLS 身份校验。不新增测试专用生产 API，也不只用模拟成功结果证明实际传输可用。
- 保留现有公开执行器接缝用于已有低层行为及类型兼容回归；只有 HTTP 无法合理观察的库级行为使用已有公开库接口，不为私有 helper 新开接口。
- 复用既有 Miniflare/workerd、独立 DNS 解码和本地 OpenSSL 经验，保留 DNS/ECH 库独立回归。ECH 应用参数、结果和日志在 HTTP 层验证；真实库握手另保留独立互操作。
- 普通测试使用受控来源、时间、取消和本地服务，不要求公网。线上互操作、连接限制、TLS 目标可达性及免费 CPU 单独记录，不用受控测试代替。

### 外部行为覆盖

1. JSON 变量、组排序、顺序动作、全量预检；旧扩展和自动政策不被静默接受，无用户函数入口或任意代码执行。
2. 域名边界、当前/原始数据、查询类型、记录字段、客户端/响应/边缘区分、缺失语义、同地址绑定及来源错误。
3. 没有显式请求动作则无上游副作用；正常结束、stop 和 return 不补查；无答案明确 SERVFAIL。
4. HTTPS/TCP/TLS 的真实协议、ID/Question 关联、完整 RCODE、合法 SERVFAIL/REFUSED/NXDOMAIN/NODATA，损坏响应拒绝。
5. 用 JSON 最近动作结果及响应条件表达顺序回退；一次动作不隐式回退、重试或竞速，保留旧答案不能冒充本次成功。
6. 必需失败终止、可选失败回滚自身、此前状态保留、最近动作结果不回滚；成功后结果更新，外部副作用不伪装撤销。
7. 超时、取消、消息超限、半帧、分段、多余数据及迟到拒绝；连接和流资源清理；整体预算不被动作重置；TLS 身份失败不降级。
8. 默认缓存、规则读写控制、动作覆盖优先级、只缩短有效期、TTL 递减和负缓存；上游/传输/查询身份隔离，命中仍运行规则、原始缓存不污染、故障不安全复用。
9. 列表两种格式、首次不可用、刷新调度边界、HTTP/部分下载/校验失败、原子替换、失败不使用旧数据、不当空集、成功恢复及作用域。
10. 入口 GET/POST、可选 JSON 同核、路径认证、拒绝时无上游副作用、HTTP 错误与 DNS 失败区别、统一收尾及默认日志脱敏。
11. 固定记录及地址/TTL/AAAA/HTTPS 修改、AD/受影响签名和扩展 RCODE；ECH 库参数及结果适配、无隐式探测、认证失败不降级。
12. 不启用 nodejs_compat 的 workerd 回归、严格类型检查、浏览器目标构建和基础库回归，不能仅凭 Node 通过宣称 Workers 可用。
13. 在线免费环境测量冷/热、缓存命中/未命中、规则规模、来源刷新及 ECH 的 CPU、Wall time 分布与资源错误，不只给平均网络耗时。

好测试只断言外部输出、协议和副作用，不锁死私有对象布局、缓存内部键或 helper 调用次数。最近动作结果通过后续规则选择的答案观察，缓存通过出站请求、TTL 和隔离结果观察。重要预期使用独立解码或服务验证，不让同一库生成预期后自证。

## Out of Scope

- 用户 JS/TS 条件或动作注册、任意函数调用、eval、请求上传代码和不可信脚本沙箱。
- 内置上游顺序回退组、响应采用白名单政策、自动重试、隐式默认上游、通用并发和竞速；JSON 显式顺序分支不在此排除之列。
- UDP、QUIC/DoQ 等本次 HTTPS/TCP/TLS 之外的上游传输；通用应用 TLS 会话。
- 自动继承旧业务、旧 AUTO、厂商路由、旧架构；文件配置回退、在线配置数据库、UI 和深度合并系统。
- 多账户、多租户、多配置入口；Bearer/查询参数访问密钥、伪装入口。
- 首版完整兼容 hosts、Adblock、Clash/Mihomo 规则语义。
- 通用最终答案缓存、随意改写缓存身份、延长安全 TTL、过期答案假装有效、自行签发 DNSSEC 或冒充旧签名仍有效。
- 默认全球响应 IP 归属库、默认 ECH 厂商、更新失败使用旧域名列表。
- 保证所有目标可达、所有任意规模配置不超 CPU、进程缓存全球一致，或将本地测试当线上配额证明。
- 本次规格更新自动开始代码迁移、调整其他票据、提交、推送或部署；线上资源和验收另行授权。
